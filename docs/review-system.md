# Operations System

## Purpose
Defines how changes are reviewed, deployed, and committed.

## Principle
Analyze before implementing.

## Commands
@review

## Rules
- Review the codebase before major changes.
- Identify side effects.
- Create a plan before implementation.
- Self-review before completion.

## Deployment Rules
- Verify builds.
- Verify environment variables.
- Verify responsiveness.
- Verify performance.
