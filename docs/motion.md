# Engineering System

## Purpose
Defines implementation standards and technical quality.

## Principle
Build scalable, maintainable, performant systems.

## Commands
@motion

## Rules
- Build mobile-first.
- Maintain accessibility.
- Optimize performance.
- Prefer React, Next.js, Tailwind, and Framer Motion.
- Avoid bloated dependencies.
- Avoid legacy patterns.
- Keep code modular.
- Use reusable components.
- Separate concerns clearly.
- Comment complex logic.
- Optimize Core Web Vitals.
