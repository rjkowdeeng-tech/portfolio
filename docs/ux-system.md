# Experience System

## Purpose
Defines how users interact with the website.

## Principle
Motion and interactions must support understanding.

## Commands
@ux

## Rules
- Mobile experience comes first.
- Validate all layouts on small screens.
- Ensure touch-friendly interactions.
- Every animation serves a purpose.
- Use scroll storytelling when appropriate.
- Favor layered transitions and subtle parallax.
- Interactions should communicate state and intent.
- Use premium hover states.
- Avoid decorative animations.
- Avoid bouncing and flashy effects.
- Motion should feel physical and deliberate.
- Use semantic markup.
- Support keyboard navigation.
- Maintain sufficient contrast.
- Respect reduced motion preferences.
- Build inclusive experiences.
